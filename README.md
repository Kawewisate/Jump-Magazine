# ผู้ช่วยครู AI (Prototype)

เว็บแอปหน้าตาคล้าย ChatGPT/Claude สำหรับครูที่ไม่ถนัด AI มี 2 โหมด:

- **🎨 ออกแบบสื่อการสอน** — บอกชื่อบทเรียน/ข้อแม้ (หรือแนบไฟล์) → AI เสนอแผนการสอน+สารบัญ+รายการรูปประกอบที่จะวาดให้เช็คก่อน → กดยืนยัน → AI เขียนเนื้อหาการสอนฉบับเต็ม (รองรับสูตร LaTeX + รูปประกอบ) → พรีวิวสวยๆ แล้วกดพิมพ์เป็น PDF เอง หรือดูเป็นสไลด์ 16:9 นำเสนอ/บันทึกเป็น PDF สไลด์
- **📝 ออกแบบแบบฝึกหัด** — บอกบท/รายละเอียด → AI สร้างแบบฝึกหัด 4 ระดับความยาก (ง่ายมาก / ปานกลาง / ประยุกต์ / ศึกษาต่อ) พร้อมรูปประกอบตรงจุดที่โจทย์บอกว่า "ดังรูป" แยกพรีวิว+พิมพ์เป็น PDF ทีละไฟล์

### 🖼️ รูปประกอบ (diagram)

AI แทรกรูปประกอบเข้าไปในเนื้อหาได้เองโดยเขียนสเปค JSON สั้นๆ (ไม่ใช่วาดพิกเซลเอง) แล้วเบราว์เซอร์จะคำนวณตำแหน่ง/วาดเป็น SVG ให้ทันที วิธีนี้ทำให้โมเดล flash ที่ไม่เก่งเรื่องพิกัดก็สร้างรูปที่ถูกต้องได้แม่นยำ รองรับ:

| กลุ่มวิชา | ชนิดรูปที่รองรับ |
|---|---|
| ฟิสิกส์ | `blocks` (วัตถุ/แรง/เชือก/พื้นผิว), `incline` (พื้นเอียง), `pulley` (รอก), `fbd` (แผนภาพแรงลัพธ์), `circuit` (วงจรไฟฟ้า), `optics` (เลนส์/กระจก) |
| เคมี | `atom` (แบบจำลองโบร์), `molecule` (สูตรโครงสร้างจาก SMILES) |
| คณิตศาสตร์ | `graph` (กราฟฟังก์ชัน/v-t), `geometry` (รูปเรขาคณิต), `solid` (ทรงสามมิติ), `numberline`, `chart` (แผนภูมิ), `venn`, `tree` (แผนภาพต้นไม้), `fraction` |
| อื่นๆ | `flow`, `cycle`, `timeline`, `mindmap`, และ `mermaid` flowchart สำหรับอัลกอริทึม |

ถ้ารูปที่โมเดลเขียนมาพัง ระบบจะขอให้โมเดลซ่อมให้อัตโนมัติ (สูงสุด 4 ครั้ง) ก่อนแสดงกล่อง fallback พร้อมสเปคดิบให้ตรวจเอง และมีปุ่ม "✏️ แก้รูปนี้" ให้สั่งแก้ไขรูปเป็นภาษาธรรมชาติได้ในหน้าแชท/การ์ดแบบฝึกหัด (ไม่ปรากฏใน PDF/สไลด์)

หน้า `diagram-gallery.html` (ไม่ได้ลิงก์จากตัวแอป) มีตัวอย่างของทุกชนิดรูป ใช้ตรวจสอบตอนพัฒนา — เปิดผ่าน static server เช่น `python -m http.server` แล้วเข้า `/diagram-gallery.html`

เป็นเว็บ **ฝั่ง client ล้วนๆ** ไม่มี backend/server — เรียก OpenRouter API ตรงจากเบราว์เซอร์ และเก็บข้อมูลทั้งหมด (ประวัติงาน, การตั้งค่า) ไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่มีข้อมูลใดถูกส่งขึ้นเซิร์ฟเวอร์ใดๆ นอกจาก OpenRouter

## วิธีรัน

**แบบง่ายที่สุด**: เปิดไฟล์ [`index.html`](index.html) ในเบราว์เซอร์โดยตรง (หรือใช้ static server เล็กๆ เช่น `npx serve .` เพื่อเลี่ยงข้อจำกัดบางอย่างของ `file://`)

**Deploy ขึ้น GitHub Pages**:
1. Push โค้ดทั้งหมดขึ้น repo บน GitHub
2. ไปที่ Settings → Pages → Source เลือก branch `main` โฟลเดอร์ `/ (root)`
3. รอสักครู่แล้วเข้าลิงก์ที่ GitHub Pages ให้มา

ไม่มี build step ไม่ต้อง `npm install` ใดๆ ทั้งสิ้น

## ตั้งค่า API key

1. ไปที่ [openrouter.ai/keys](https://openrouter.ai/keys) เพื่อสร้าง API key ของตัวเอง (มีเครดิตฟรีให้เริ่มต้น)
2. เปิดเว็บแอป → กด "⚙️ ตั้งค่า" ที่มุมล่างซ้าย → วาง API key → บันทึก

> **⚠️ สำคัญเรื่องความปลอดภัย**: API key จะถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์คุณเท่านั้น **ห้ามใส่ API key ลงในโค้ดที่จะ commit ขึ้น GitHub โดยตรง** เพราะถ้า repo เป็น public ใครก็เห็น key และเอาไปใช้ยิงเครดิตของคุณได้ทันที ครูแต่ละคนที่ใช้เว็บนี้ต้องกรอก API key ของตัวเองผ่านหน้า Settings เท่านั้น

## Model ที่ใช้

ตั้งค่า default ไว้ที่ `deepseek/deepseek-v4-flash-0731` พร้อม reasoning effort ระดับ `medium` — แก้ไขได้จากหน้า Settings เช่นกัน หากในอนาคต model id เปลี่ยนหรือใช้งานไม่ได้ ให้เข้าไปแก้ในหน้า Settings ได้เลยโดยไม่ต้องแก้โค้ด

### โมเดลฟรีสำรอง (ใช้ยามฉุกเฉิน)

ในหน้า Settings จะมีปุ่มลัดให้สลับโมเดลได้ทันที เผื่อกรณีเครดิต OpenRouter ของโมเดลหลักหมดกะทันหัน:

- `google/gemma-4-31b-it:free`

โมเดลกลุ่ม `:free` นี้ไม่มีค่าใช้จ่าย แต่ **คุณภาพและความแม่นยำอาจสู้โมเดลหลักไม่ได้** โดยเฉพาะการเขียนสูตร LaTeX และภาษาไทยที่ซับซ้อน แนะนำให้ใช้เป็นทางเลือกชั่วคราวเท่านั้น แล้วสลับกลับมาใช้โมเดลหลักทันทีที่เติมเครดิตแล้ว

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บทั้งหมด |
| `styles.css` | ธีม/ดีไซน์ |
| `storage.js` | จัดการ localStorage (settings + ประวัติงาน) |
| `api.js` | เรียก OpenRouter API (streaming) + system prompts |
| `fileparse.js` | ดึงข้อความจากไฟล์ .pdf / .docx / .txt ที่ครูอัปโหลด |
| `diagrams-core.js` | ตัวกลางของระบบรูปประกอบ: registry, parser, SVG helpers, ตัวรวม prompt guide |
| `diagrams-science.js` | renderer ฟิสิกส์/เคมี (blocks, incline, pulley, fbd, circuit, optics, atom, molecule) |
| `diagrams-math.js` | renderer คณิตศาสตร์ (graph, geometry, solid, numberline, chart, venn, tree, fraction) |
| `diagrams-concept.js` | renderer แผนผังทั่วไป (flow, cycle, timeline, mindmap) |
| `print.js` | เรนเดอร์ markdown+LaTeX+รูปประกอบ เป็น HTML พรีวิวสำหรับพิมพ์ |
| `slides.js` | แปลงเนื้อหาบทเรียนฉบับเต็มเป็นสไลด์นำเสนอ 16:9 |
| `app.js` | ตัวควบคุมหลัก UI/flow ของทั้ง 2 โหมด |
| `diagram-gallery.html` | หน้าทดสอบ renderer รูปประกอบทุกชนิด (dev only) |
| `tools/eval-diagrams.mjs` | สคริปต์ยิงโจทย์จริงใส่ deepseek-v4-flash เพื่อประเมินความแม่นยำของรูปประกอบ |

## ข้อจำกัดที่รู้อยู่แล้ว (เป็น prototype)

- ไม่มีระบบผู้ใช้/login — ข้อมูลผูกกับเบราว์เซอร์เครื่องนั้นเครื่องเดียว
- ไฟล์แนบขนาดใหญ่มากจะถูกตัดข้อความที่ดึงได้ไว้ที่ ~15,000 ตัวอักษรแรก กันชนข้อจำกัดของโมเดล
- การจัดหน้า PDF สร้างด้วย `html2pdf.js` (html2canvas + jsPDF) ควบคุมการแบ่งหน้าเอง ไม่ได้พึ่ง print engine ของเบราว์เซอร์
